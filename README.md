# Nummo

App móvil para gestionar **gastos y presupuestos personales**, siguiendo el método de presupuesto por sobres. Proyecto personal para aprender React Native.

## Stack

- Expo (SDK 57) · React Native · TypeScript
- expo-router (navegación)
- SQLite + Drizzle ORM (datos, local-first)

## Desarrollo

```bash
npm install
npx expo start
```
